Panduan Memasang Linux untuk Pemula

💡 Kabar Baik: Anda bisa mencoba Linux lewat Live USB tanpa menghapus atau merusak data Windows Anda sama sekali!
  1. Unduh Berkas ISO: Klik tombol "Unduh ISO Resmi" pada distro pilihan Anda (ukuran berkisar 1GB - 3GB).
  2. Buat Bootable USB: Gunakan aplikasi gratis seperti Rufus atau Ventoy di Windows. Colok flashdisk min. 8GB lalu pilih file ISO tadi.
  3. Boot Lewat Flashdisk: Restart laptop, lalu tekan tombol Boot Menu saat laptop baru menyala (biasanya tombol F12, F2, atau Esc).
  4. Coba Live Mode: Pilih "Try Linux". Anda bisa mengetes WiFi, keyboard, audio, dan browsing. Jika cocok, Anda bisa klik tombol "Install to Disk" untuk memasangnya permanen.

Cara Melihat Spek di Windows

Cara 1: Lewat Task Manager (Paling Cepat)

Tekan tombol Ctrl + Shift + Esc, lalu buka tab Performance.

  • CPU: Menampilkan jumlah Cores dan Logical Processors.
  • Memory: Menampilkan total kapasitas RAM (misal 4GB atau 8GB).
  • Disk: Menampilkan jenis drive (SSD atau HDD).

Cara 2: Lewat dxdiag

Tekan Windows + R, ketik dxdiag lalu tekan Enter.

Pada tab System, lihat apakah OS Anda 32-bit atau 64-bit serta total kapasitas Memory.
