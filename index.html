Panduan Memasang Linux untuk Pemula

Kabar Gembira: Anda Bisa Coba Dulu Tanpa Install!

Hampir semua Linux modern memiliki fitur "Live USB". Artinya, Anda bisa mencoba sistem operasi Linux langsung dari flashdisk tanpa menyentuh data Windows atau harddisk Anda sama sekali.

1
Download File ISO

Kunjungi website resmi distro pilihan Anda (tersedia tombol di kartu hasil) lalu unduh berkas berekstensi .iso (ukuran berkisar 1GB - 3GB).

2
Buat Bootable Flashdisk

Gunakan aplikasi gratis seperti Rufus atau Ventoy di Windows. Colokkan flashdisk (min. 8GB), pilih file ISO tadi, lalu klik Start.

3
Boot Lewat Flashdisk

Restart komputer Anda, lalu tekan tombol Boot Menu berkali-kali saat logo komputer menyala (biasanya tombol F12, F2, F9, atau Esc).

4
Coba & Pasang (Dual-Boot)

Pilih "Try Linux". Anda bisa browsing, tes audio, WiFi. Jika merasa cocok, klik ikon "Install" di desktop untuk memasangnya berdampingan dengan Windows (Dual-Boot) atau menggantikannya.

Cara Melihat Spek Komputer di Windows

Cara 1: Lewat Task Manager (Paling Cepat)

Tekan kombinasi tombol Ctrl + Shift + Esc, lalu klik tab Performance.

  • CPU: Menampilkan nama prosesor, kecepatan, dan jumlah Cores / Logical processors.
  • Memory: Menampilkan total kapasitas RAM (misal 4.0 GB atau 8.0 GB).
  • Disk: Menampilkan tipe penyimpanan (SSD atau HDD) dan sisa kapasitas.
  • GPU: Menampilkan tipe kartu grafis (Intel, NVIDIA, atau AMD).

Cara 2: Lewat DirectX Diagnostic (dxdiag)

Tekan Windows + R, ketik dxdiag lalu tekan Enter.

Pada tab System, Anda bisa melihat apakah OS Anda 32-bit atau 64-bit serta total kapasitas Memory RAM secara akurat.
